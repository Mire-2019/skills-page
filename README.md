# skill-adapt（本地化版）

把外部 skill 当作「原料」，经三道工序（**价值分析 → 整合分析 → 适配改造**）处理后，产出「已适配到本地、可拍板可装」的成品 skill。

本仓库为 **本地化改造版**：在原版思路基础上，加入了作者个人环境的约定（全中文正文、D 盘落盘、三层基线、安全一票否决、隐藏价值观剥壳），核心流程与原作者一致但细节以本地为准。

## 用法

当拿到一个新 skill 来源（B站/公众号/GitHub 仓库/一句话指令）时，由 agent 读取 [SKILL.md](SKILL.md) 触发三道工序；每道工序结束处等用户决策，最后用户拍板后才安装。
